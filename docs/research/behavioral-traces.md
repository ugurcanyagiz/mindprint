# MINDPRINT Behavioral Traces

## Principle

Behavioral traces are observed interaction records. Construct assignments are
hypotheses that require empirical validation.

No single trace is interpreted as intelligence.

Fast response does not mean high intelligence. More information requests do
not automatically mean better cognition. Answer revision is not automatically
adaptive.

## Trace catalog

| Trace | Category | Primary hypothesized constructs | Key limitation |
| --- | --- | --- | --- |
| signal-selection | process | Attention & Cognitive Control | Click/selection behavior is not gaze or covert attention |
| decision | outcome | Model Formation; Epistemic Judgment | Multiple processes can generate the same decision |
| confidence | process | Metacognitive Regulation | Response style and evidence context matter |
| information-request | process | Attention; Metacognition; Epistemic Judgment | More requests are not intrinsically better |
| revision | process | Learning; Metacognition; Epistemic Judgment | Direction and evidence quality determine appropriateness |
| rule-prediction | outcome | Model Formation; Learning Dynamics | Numeracy and working memory can contribute |
| rule-change-detection | process | Learning Dynamics | Detection latency is contextual, not a standalone speed score |
| transfer-choice | outcome | Knowledge Transfer; Model Formation | Surface cues and domain familiarity can contaminate inference |
| ai-reliance | process | Augmented Cognition; Epistemic Judgment | Reliance is meaningful only relative to AI quality |
| interruption | process | Attention & Cognitive Control | Recovery in one task is not a general attention trait |
| evidence-update | process | Epistemic Judgment; Metacognitive Regulation | Belief movement must be judged relative to evidence strength |

## Outcome signals

Examples:

- final diagnostic selection;
- correct rule prediction;
- correct structural transfer;
- evidence-selection quality;
- final decision.

Outcome signals resemble conventional performance observations but remain
specific to the environment.

## Process signals

Examples:

- selection sequence;
- confidence trajectory;
- belief trajectory;
- hypothesis switching;
- rule-change detection point;
- old-rule errors;
- information request sequence;
- interruption recovery;
- AI acceptance or verification.

Process signals are not included in the production score in Milestone 14.

## Trace interpretation

A valid future observation generally requires multiple pieces:

context + environmental manipulation + trace + outcome + relevant confounds.

For example, a rule-change-detection trace can contribute to a hypothesis about
adaptive updating only when the actual change point and feedback structure are
known.

## Confounds

Dynamic traces may be influenced by:

- gaming familiarity;
- graph literacy;
- mouse/trackpad familiarity;
- touchscreen familiarity;
- visual acuity;
- color vision;
- motor speed;
- reading speed;
- device performance;
- refresh rate;
- digital literacy;
- AI familiarity.

These are measurement risks, not current adjustment factors.

## Timing

Trace timestamps support event ordering and process description.

They must not be converted into a faster-equals-smarter interpretation.

Precise reaction-time inference would require explicit validation of browser,
device, rendering, input, and task-timing characteristics.
