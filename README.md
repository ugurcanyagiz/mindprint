# MINDPRINT

MINDPRINT is an experimental cognitive assessment prototype exploring how people reason, adapt, evaluate evidence, filter information, calibrate confidence, and transfer knowledge.

## Status

Foundation scaffold only. Assessment content and scoring will be implemented in later milestones.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Client-side state and localStorage
- No backend, database, authentication, or paid APIs in V0.1

## Positioning

MINDPRINT is **not** an IQ test, clinical instrument, diagnostic tool, or standardized population assessment. Any scores in the prototype represent performance within the assessment only.

## Development

```bash
npm install
npm run dev
```

Production check:

```bash
npm run check
npm run build
```
